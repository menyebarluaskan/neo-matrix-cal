# Neo Matrix Calculator

A modern remake of Matrix Calculator using next.js

## Main Features

- [x] Add Matrix Variables
- [ ] Calculate Matrix Variables
  - [ ] Formula Parser
  - [x] Matrix Addition
  - [ ] Matrix Subtraction
  - [ ] Matrix Multiplication
  - [ ] Matrix Determinant
  - [ ] Matrix Inverse
  - [ ] Matrix Rank
  - [ ] Matrix Transpose
